

**Report. Track. Improve Your City.**

CivicTrack is a civic-tech platform that helps citizens report local civic issues, track their complaints, and stay informed about the progress of problems in their area. It is designed to make communication between citizens and local authorities more transparent, accessible, and efficient.

## Features

* Report civic issues such as potholes, garbage, broken streetlights, water leakage, and damaged public infrastructure.
* View reported issues on an interactive map.
* Track the status of complaints from submission to resolution.
* Upload photos as evidence while reporting an issue.
* Receive updates as the complaint progresses.
* Fully responsive design for desktop, tablet, and mobile devices.
* Modern dark-themed interface with a clean user experience.

## Issue Status

| Status       | Description                              |
| ------------ | ---------------------------------------- |
| Reported     | The issue has been submitted.            |
| Under Review | The complaint is being reviewed.         |
| In Progress  | Work has started on resolving the issue. |
| Resolved     | The issue has been fixed.                |

## Why CivicTrack?

Many civic complaints disappear into systems where citizens have little visibility into what happens next. CivicTrack aims to solve this by providing a simple platform where people can report issues, monitor their progress, and encourage greater accountability.

## Use Cases

* Broken streetlights
* Garbage and sanitation issues
* Water leakage
* Damaged public infrastructure
* Public space maintenance
* Traffic and road safety concerns
